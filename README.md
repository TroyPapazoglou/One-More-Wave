# ONE MORE WAVE

*A minimalist survival game about lasting just a little longer.*

Survive endless waves of enemies, dodge deadly attacks, and push your survival time further with every run.

## Download

Want to give it a try?

### Windows

Download the ZIP file from the latest release.

Extract the ZIP to a folder.

Run OneMoreWave.exe to play.


### Android

Download the Android ZIP file from the latest release onto your phone.

Open your Files app and extract the ZIP.

Open the extracted folder and tap the .apk file to install the game.

If prompted, allow your browser or Files app to install unknown apps, then continue with the installation.

Once installed, open One More Wave and play!

Note: Android may show a security warning because the game isn't installed through the Google Play Store.

This is an early development build. Bugs and gameplay changes are expected!

## Features

- **Wave-based survival** — see how long you can stay alive as the challenge ramps up.
- **Distinct enemy types** — recognise threats by their shape, colour, and behaviour.
- **Increasing difficulty** — survive as enemy spawn ramps up.
- **Personal best tracking** — compete against your longest survival time.
- **Minimalist visuals** — clean geometric designs keep the action readable.

## Development

One More Wave is an game project focused on building a simple, survival experience.

Current development focuses on enemy behaviours, escalating difficulty, gameplay feedback, and making every run feel worth attempting again.

## Source Code

One More Wave is developed using Unity 6.6+ and C#.

This repository contains the game's source code and Unity project files. It is publicly available for anyone interested in exploring the project's implementation, gameplay systems, enemy behaviours, and overall development.

If you're interested in the technical side of the project, feel free to explore the source code!
